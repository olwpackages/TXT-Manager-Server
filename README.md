# Текст

### Лаконичный TXT-редактор для Android

Пишите заметки на телефоне, отправляйте их на свой компьютер и устанавливайте обновления через собственный HTTPS-сервер в локальной сети.

## Возможности

| | Функция | Что это даёт |
|:---:|---|---|
| ✍️ | Удобный редактор | Открывайте и сохраняйте TXT, редактируйте текст, отменяйте и повторяйте действия |

## Как это устроено

```text
┌──────────────────┐      HTTPS · Wi-Fi       ┌──────────────────────┐
│  Android «Текст» │ ───────────────────────▶ │ Node.js на компьютере│
│                  │ ◀─────────────────────── │                      │
└──────────────────┘   TXT · JSON · APK      └──────────┬───────────┘
                                                        │
                                      ┌─────────────────┴──────────────┐
                                      │                                │
                               received/*.txt                  update/Tekst.apk
```

Сервер работает на вашем компьютере и доступен устройствам в той же Wi-Fi сети. Внешний хостинг и сторонние npm-пакеты не нужны. Node.js принимает заметки в `outputs/wifi-server/received`, а для обновлений отдаёт APK и описание версии из `outputs/update`.

## Быстрый старт

Понадобятся Node.js 18+, OpenSSL, Android SDK 35 и JDK 17+. Установите Node.js и откройте PowerShell в корне проекта.

### 1. Укажите свои сетевые параметры

Узнайте локальный IPv4-адрес компьютера, например адрес Wi-Fi адаптера. Придумайте длинный случайный токен и задайте их в текущем окне PowerShell:

```powershell
$ip = "<IP компьютера в локальной сети>"
$token = "<ваш длинный случайный токен>"
$tlsDir = Join-Path $PWD "local-tls"
New-Item -ItemType Directory -Force $tlsDir | Out-Null
```

### 2. Создайте TLS-сертификат

Сертификат привязывается к IP компьютера. Понадобится OpenSSL, например из Git for Windows.

```powershell
openssl req -x509 -newkey rsa:2048 -nodes -sha256 -days 365 `
  -keyout (Join-Path $tlsDir "server-key.pem") `
  -out (Join-Path $tlsDir "server-cert.pem") `
  -subj "/CN=$ip" `
  -addext "subjectAltName=IP:$ip" `
  -addext "extendedKeyUsage=serverAuth"
```

### 3. Запустите сервер

```powershell
$env:WIFI_SERVER_CERT = (Resolve-Path (Join-Path $tlsDir "server-cert.pem")).Path
$env:WIFI_SERVER_KEY = (Resolve-Path (Join-Path $tlsDir "server-key.pem")).Path
$env:WIFI_UPLOAD_TOKEN = $token
node .\outputs\wifi-server\server.js
```

Разрешите Node.js входящие подключения для частной сети в брандмауэре Windows. Сервер сообщит LAN-адреса и будет слушать порт `8765`. Оставьте это окно открытым, пока пользуетесь передачей и обновлениями.

## Передача файлов

Чтобы приложение могло отправлять заметки, добавьте параметры **своей** сети в локальный корневой `gradle.properties`:

```properties
wifiServerIp=<IP компьютера в локальной сети>
wifiUploadToken=<тот же токен, что задан серверу>
wifiCertPin=<SHA-256 отпечаток сертификата>
```

Вычислите отпечаток сертификата:

```powershell
openssl x509 -in .\local-tls\server-cert.pem -outform DER | openssl dgst -sha256
```

В `wifiCertPin` вставьте hex-строку после `=` без пробелов и разделителей. Соберите приложение с этими параметрами. На телефоне откройте меню **Действия → Отправить заметку**. Сервер сохранит TXT в `outputs/wifi-server/received`; если имя занято, он добавит к нему номер.

## Обновления приложения

На телефоне откройте **Действия → Проверить / скачать APK** и укажите адрес сервера:

```text
https://<IP компьютера в локальной сети>:8765
```

Приложение проверит `outputs/update/latest.json`, сравнит `versionCode` и предложит скачать APK, если доступна более новая версия. Установка запускается системным установщиком Android и требует подтверждения пользователя.

Чтобы опубликовать обновление на своём сервере:

1. Соберите APK с той же подписью, что и установленное приложение.
2. Скопируйте его в `outputs/update/Tekst.apk`.
3. Укажите новую версию в `outputs/update/latest.json`:

```json
{
  "versionCode": 44,
  "versionName": "1.43",
  "notes": "Краткое описание изменений"
}
```

`versionCode` должен быть больше установленного. Сервер автоматически раздаёт JSON по `/update.json`, а APK по `/Tekst.apk`. Для автоматической проверки при запуске сохраните адрес сервера в приложении и включите проверку в настройках.

## Сборка приложения

Задайте `wifiServerIp`, `wifiUploadToken` и `wifiCertPin` в локальном `gradle.properties`, затем выполните:

```powershell
gradle assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Скрипт `work/build_update.ps1` собирает debug APK, увеличивает номер версии и подготавливает файлы для сервера.

## Безопасность и локальные файлы

- Не публикуйте токен, `server-key.pem` и `local-tls`.
- Не коммитьте локальный `gradle.properties`, если в нём есть секреты.
- Параметры, встроенные в APK, можно извлечь. Используйте отдельный токен для личного сервера в доверенной сети.
- Если пересоздали сертификат, обновите `wifiCertPin` и пересоберите приложение.
